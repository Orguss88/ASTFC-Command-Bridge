ASTFC Voice Protocol — Commands 0.0.1
Star Citizen 4.10.2 LIVE · keyboard + mouse default keybinds

HOW TO USE
  1. Start the app. It begins in SIMULATION: it shows what it heard but presses nothing.
  2. Say a phrase below and watch the dashboard. Try a few before going live.
  3. To fly with it: Settings > Game input > Live keys. Keys only go to Star Citizen
     while its window is in front.
  4. If you changed a keybind in game, change it in the app too (Voice Commands > Edit).

SAFETY WORDS
  "Confirm mode."  The app asks this before "engage quantum" / "activate scan" unless you set
                   that mode by voice in the last 30 s. Answer "mode confirm" within 10 s.
  "Are you sure?"  Asked before self destruct, goon mode and quitting the game.
                   Answer "affirmative" within 5 s, or "negative" to cancel.
  "Command not bound."  The command exists but has no key in Star Citizen's defaults.

KNOWN QUIRKS
  - Hyun (mining + salvage ship): "salvage mode" may open mining mode first. Say it again,
    or say "next mode" to cycle.
  - Mode changes made by hand (stick button, middle mouse) are invisible to the app, so it may
    ask "Confirm mode." even when you are already in the right mode.
  - Scan mode and mining mode are toggles: saying them twice switches the mode off again.
  - Auto land only works with gear down, close above your assigned pad. Not yet tested on the Hyun.
  - The app listens to the Windows default microphone (Settings > System > Sound).

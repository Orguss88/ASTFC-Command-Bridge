**First test build** for ASTFC members and friends.

### Download
Get **`ASTFC-Voice-Protocol-0.0.1-windows.zip`** below (Assets). Unzip the whole folder, then run `ASTFC Voice Protocol.exe`.
Windows may warn that the app is unrecognised: **More info → Run anyway**.

### What's in it
- Offline voice recognition with the speech engine built into Windows. Nothing leaves your PC.
- 71 voice commands with Star Citizen 4.10.2 default keys; 21 tested in game. See `Commands 0.0.1.txt` (also inside the zip).
- Starts in simulation; **Live keys** in Settings, and keys only go to Star Citizen while it is in front.
- Safety prompts: "Confirm mode." → "mode confirm"; "Are you sure?" → "affirmative" / "negative"; "Command not bound."
- ASTFC Standard and High Contrast themes, both colour-blind safe; every status has an icon and a word; text size 100-150 %; keyboard shortcuts.
- Edit any command's phrases, key or hold time; export / import your changes.

### Known limits
- Uses the Windows default microphone; no push-to-talk yet.
- One command profile; macros are planned.
- The app isn't code-signed yet.
